Data / Evaluation

데이터에서 혼잡 판단까지

데이터 범위, 라벨 불균형, 오분류 구조를 차례로 확인해 모델의 점수뿐 아니라 실제로 어떤 상황을 구분하는지 살폈습니다.

01 / Coverage

계절을 한 번 모두 통과한 201만 건

서울시 138개 지점의 2025년 교통량과 Open-Meteo 시간별 날씨를 결합했습니다. 월별 데이터가 한쪽 계절에 치우치지 않아 온도·강수·공휴일 변화가 함께 들어갑니다.

  • 시간 범위: 2025년 1월–12월, 총 2,015,862행
  • 공간 범위: 138개 측정 지점과 유입·유출 방향
  • 맥락 정보: 기온, 비·눈, 운량, 요일, 주말, 명절 전후와 연휴 여부
02 / Target design

도로마다 다른 혼잡 기준을 만들었다

모든 도로에 하나의 절대 교통량 기준을 쓰지 않고, 측정 지점과 방향별 교통량의 70퍼센타일을 임계값으로 삼았습니다. 평소 통행량이 다른 도로도 자신의 패턴 안에서 혼잡을 정의할 수 있습니다.

평가 기준: 7:3 불균형이 있으므로 accuracy와 함께 혼잡 클래스 precision·recall·F1을 확인했습니다.
03 / Error structure

혼잡 103,992건을 정확히 찾았다

실제 혼잡 121,190건 중 103,992건을 맞혔고 17,198건을 놓쳤습니다. 원활 구간을 혼잡으로 판단한 경우는 17,692건으로, 두 방향 오류가 비슷한 크기를 보였습니다.

Engineering deep dive

시계열 맥락을 분류 입력으로 바꾸기

날짜와 위치만 넣는 모델에서 끝내지 않고, 지역별 임계값과 한국 공휴일 문맥을 명시적인 feature로 설계했습니다.

01 / Feature engineering

수치형 14개와 범주형 8개를 한 파이프라인으로

기온·강수·시간·요일·명절 전후는 StandardScaler로 정규화하고, 지점·방향·구간·날씨 설명·공휴일 이름은 OneHotEncoder로 변환했습니다. 학습과 추론이 같은 컬럼 순서를 사용하도록 Pipeline에 전처리와 모델을 묶었습니다.

02 / Training

201만 건을 계층 비율 그대로 분할

stratify=y로 train과 test의 혼잡 비율을 모두 30.1%로 유지했습니다. MLP는 52회 반복에서 조기 종료됐고 validation score 0.9138, 최종 loss 0.1738을 기록했습니다.

Split / Model크기 또는 성능의미

03 / Inference

예측을 실제 이동 경로 비교로 연결

강서구에서 노량진으로 이동하는 세 가지 경로와 복귀 경로 두 가지를 구성하고, 각 경로에 포함된 측정 지점의 시간대별 혼잡을 예측합니다. 2025년은 로컬 날씨를, 그 외 날짜는 Open-Meteo forecast 또는 archive 데이터를 사용합니다.

  1. Route mapping올림픽대로·강서 내부도로·신월–여의도 축의 측정 지점 구성
  2. Weather fallback정확한 날짜가 없으면 같은 달·시간대 평균값으로 대체
  3. Calendar context설날·추석 구간, 공휴일 전후, 장기 연휴 feature 생성
  4. Result summary경로별 혼잡 지점과 시간대를 비교해 추천 근거 제공
03 / Retrospective

점수에서 사용할 수 있는 예측으로

담당 범위

교통량과 날씨 데이터 결합, 지점·방향별 혼잡 임계값 생성, 22개 feature 설계, MLP 학습·평가와 강서구–노량진 경로 예측 프로그램을 전체 구현했습니다.

핵심 판단

혼잡은 도로마다 기준이 달라야 하므로 전역 임계값 대신 지점·방향별 70퍼센타일을 사용했습니다. 또한 정확도 하나가 아닌 혼잡 F1과 혼동행렬을 함께 봐 실제 탐지 성능을 확인했습니다.
